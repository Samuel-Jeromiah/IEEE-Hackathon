# Bundled fonts

All three font families are licensed under the **SIL Open Font License 1.1**. The full license texts are in the `LICENSE-*.txt` files next to this one. The fonts are bundled so the app works with no internet connection.

The files are the Latin subsets in woff2 format, taken from the [fontsource](https://fontsource.org) npm packages (`@fontsource/*@5`).

| Family | Files | Copyright |
|---|---|---|
| Atkinson Hyperlegible | `atkinson-hyperlegible-latin-{400-normal,400-italic,700-normal}.woff2` | 2020 Braille Institute of America, Inc. |
| Barlow Condensed | `barlow-condensed-latin-{600,800}-normal.woff2` | 2017 The Barlow Project Authors |
| JetBrains Mono | `jetbrains-mono-latin-{400,700}-normal.woff2` | 2020 The JetBrains Mono Project Authors |
